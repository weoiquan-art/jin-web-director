# Visual Audit Template

系统化审美检查清单，确保设计质量一致。每次审查 5 分钟。

## ⚡ 5 分钟快速检查

在设计完成后，用以下清单快速评审：

- [ ] **对比度** ≥ 4.5:1 (WCAG AA 标准) — 深色文字 + 浅色背景
- [ ] **层级清晰** — 1 个主要信息，2-3 个支撑层，不超过 5 个视觉权重
- [ ] **间距系统** — 所有间距来自系统 (4px/8px/16px/24px/32px)，无随意值
- [ ] **字体族** ≤ 2 个 — 避免视觉噪音
- [ ] **色彩** ≤ 5 种 + 1 种中性 — 控制调色板
- [ ] **空白** ≥ 30% — 不拥挤，呼吸感充足
- [ ] **对齐** — 所有元素对齐到栅格，无微像素偏移
- [ ] **响应式** — 手机/平板/桌面布局切换流畅，无重排

## 对比度速查表 (WCAG 标准)

| 字体大小 | 权重 | 最小比例 | ✅ 通过例子 | ❌ 失败例子 |
|---------|------|---------|----------|----------|
| <18px | 任意 | 4.5:1 | #333 + #FFF | #777 + #FFF |
| 18px+ | 任意 | 3:1 | #666 + #FFF | #AAA + #FFF |
| 18px+ | ≥700 | 3:1 | #777 + #FFF | - |

**快速检查工具：** Chrome DevTools → Inspect → Contrast ratio

## 视觉层级检查表

### 信息优先级

```
1️⃣ 主标题 (H1)
   ↓ 最大、最突出、通常是品牌色或黑色
   ↓ 阅读顺序第一

2️⃣ 关键信息 (H2, 主 CTA, 英雄图)
   ↓ 次大、次突出、通常次色或对比度高
   ↓ 阅读顺序第二

3️⃣ 支撑内容 (正文, 次 CTA, 卡片标题)
   ↓ 中等大小、中等对比度、通常灰色
   ↓ 阅读顺序第三

4️⃣ 辅助内容 (标签, 日期, 脚注)
   ↓ 小、低对比度、浅灰色
   ↓ 阅读顺序最后
```

**检查方法：** 眯眼看 3 秒，能否一眼看出主要信息？

## 间距与密度检查

| 检查项 | 标准 | 检查方法 |
|--------|------|---------|
| 段间距 | ≥ 1.6em 行高 | 段落之间 > 行高 |
| 元素间距 | ≥ md (16px) | 相邻块元素间距 |
| 内边距 | ≥ sm (8px) 按钮, ≥ md (16px) 卡片 | 框内内容与边框距离 |
| 水平空白 | 页面宽度 - 内容宽度 ≥ 2×md | 左右各 ≥ 16px 最小 |
| 垂直空白 | 内容高度 ≤ 70% 视口高度 | 不拥挤堆积 |

**密度评分：**
- ✅ 宽松 (30%+ 空白) — 高端, 现代感
- ✓ 适中 (20-30% 空白) — 标准, 平衡
- ⚠️ 紧凑 (<20% 空白) — 工具类, 需谨慎

## 字体配对审查

### 同源配对 (安全)
| 配对 | 用途 | 审查标准 |
|------|------|---------|
| Sans + Sans | 现代, 简洁 | 对比度≥3级 (粗细, 特性不同) |
| Serif + Serif | 传统, 高级 | 粗体+常规, 避免中等权重 |
| Serif + Sans | 混搭 | Serif = 标题, Sans = 正文 |

### 检查清单
- [ ] 标题字体 和 正文字体 > 3 级差异 (大小/粗细/风格)
- [ ] 无超过 2 种字体系列
- [ ] 行高 ≥ 1.5 (正文 ≥ 1.6)
- [ ] 最大行宽 ≤ 75 字 (中文 ≤ 36 字)

## 颜色搭配检查

### 色彩噪音诊断

| 症状 | 原因 | 修复 |
|------|------|------|
| 看起来"廉价" | 色彩过多或饱和度不一 | 限制 ≤ 5 色, 统一饱和度 |
| 难以阅读 | 前景+背景对比不足 | 用对比度检查工具, ≥4.5:1 |
| 视觉乱 | 多种色系混用 | 选择单一色系 (冷/暖/中性) |
| 单调 | 只用灰度 + 1 色 | 加入 1-2 个补色强调点 |

### 色彩应用规则
- ✅ 1 个主色 (品牌, CTA)
- ✅ 1 个次色 (次要动作, 链接)
- ✅ 1 个强调色 (错误/成功提示)
- ✅ 5 级灰度 (纯黑/深灰/中灰/浅灰/纯白)
- ✅ 背景色与文字色 ≥ 3 个组合

## 网格与对齐检查

| 检查项 | 标准 | 方法 |
|--------|------|------|
| 栅格一致性 | 4px 基准栅格 | Chrome DevTools → Rendering → Show layer borders |
| 左对齐 | 所有内容块左边界对齐 | 拉竖直参考线 |
| 间距一致 | 相似元素间距相同 | 尺子工具或 DevTools measure |
| 水平居中 | 居中元素左右间距相等 | 检查 margin-left = margin-right |

| 断点 | 宽度 | 检查项 | 标准 |

| | | 表格 | 可滚动或压缩列 |

## 无障碍设计检查

| 检查项 | 标准 | 方法 |
|--------|------|------|
| 颜色依赖 | 不能仅用颜色区分信息 | 添加 icon/text/pattern |
| 焦点顺序 | Tab 键顺序合理 | 键盘导航测试 |
| 跳过链接 | "Skip to main" 链接存在 | 检查 HTML |
| 图片 alt | 有意义的 alt 文本 | 检查 \<img alt="..."> |
| 对比度 | WCAG AA (4.5:1) | 用工具检查 |

## 性能视觉检查

| 检查项 | 标准 | 症状 |
|--------|------|------|
| 加载时间 | <2s | 图片闪烁/FOUT 字体延迟 |
| 滚动帧率 | 60fps | 卡顿/不流畅 |
| 动画 | 300-500ms | 太快显得廉价/太慢显得卡 |
| 长列表 | 虚拟滚动 | 滚动时卡顿 |

## 快速修复清单

常见问题 → 快速修复：

| 问题 | 修复 |
|------|------|
| 对比度低 | 加深文字 or 浅化背景 |
| 看起来乱 | 增加间距, 减少颜色 |
| 难以聚焦 | 突出主标题/CTA, 淡化配角 |
| 移动端乱 | 改 1 列, 增加行间距 |
| 字体显得廉价 | 加大字号, 增加行高到 1.6+ |
| 卡片压抑 | 加内边距, 减少卡片数/行 |
| 模糊焦点 | 移除不必要颜色, 集中 ≤ 1 CTA |
