# SEO and shareability: help the right page be understood

SEO supports honest discovery; it is not a reason to stuff keywords or fabricate authority.

## Per-page essentials

- one clear page topic and a meaningful `<title>`;
- useful meta description that matches visible page content;
- semantic heading hierarchy, readable copy, and descriptive links;
- canonical URL when the site has duplicate routes or query variants;
- Open Graph/social metadata and a representative share image where the project needs sharing;
- meaningful image alternative text and filenames/asset descriptions that aid maintenance.

## Site-level essentials

- use crawlable navigation and working internal links;
- provide sitemap/robots configuration where appropriate to the deployed site;
- handle redirects deliberately when routes change;
- preserve page meaning during client-side navigation;
- avoid hiding core content exclusively behind animation, images of text, or unindexed widgets.

## Local-business and course considerations

- Use confirmed names, service area, contact routes, hours, and offer details consistently.
- Do not create fake location pages, invented reviews, fake availability, or unverified pricing solely to attract traffic.
- For courses, describe outcomes, sample materials, audience, delivery, price/refund facts, and access conditions only when confirmed.

## Verification

After release, open the public URL, inspect metadata/share preview where available, check key internal links and redirects, and record any search/discovery work that remains outside the codebase.
